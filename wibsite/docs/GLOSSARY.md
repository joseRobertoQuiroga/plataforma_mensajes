# Wibsite Business — Glosario

| Término | Sigla | Definición | Contexto |
|---------|-------|------------|----------|
| ADR | Architecture Decision Record | Registro de decisión arquitectónica con contexto, decisión y consecuencias | Documentación técnica |
| Authelia | - | Servidor de autenticación SSO open-source con 2FA | SSO, gateway unificado |
| Canal | - | Medio de mensajería (WhatsApp, Messenger, TikTok, SMS, Email) | Campañas multi-canal |
| Chatwoot | - | Sistema de inbox omnicanal open-source | Inbox de mensajes entrantes |
| Dify | - | Plataforma de orquestación de IA low-code | Workflows de clasificación y generación de contenido |
| Entrega | - | Estado de un mensaje enviado a un contacto | Tracking de campañas |
| Gateway | - | Punto de entrada unificado que centraliza autenticación, routing y seguridad | Nginx + Authelia |
| Helper Node | - | Servicio Express.js con lógica de integración personalizada | Campañas, tracking, webhooks, scoring |
| Hub | - | Centro de control unificado visual con estado de servicios y documentación interactiva | `frontend/` (Next.js) |
| Lead | - | Cliente potencial identificado y clasificado por IA | CRM, scoring, campañas |
| LED | - | Indicador visual de estado de canal (verde/rojo/amarillo) | Dashboard de monitoreo |
| Namespace | - | Espacio de nombres global en Twenty CRM para campos custom | Twenty CRM, custom fields |
| n8n | - | Orquestador de flujos visual open-source | Automatización de procesos |
| OpenRouter | - | Plataforma unificada de APIs de LLM con múltiples modelos | Proveedor LLM actual |
| Opt-Out | - | Solicitud de un cliente de no recibir más mensajes | Cumplimiento, canales |
| Plugin Daemon | - | Servicio de gestión de plugins de modelos en Dify | Conexión a LLMs |
| Provider | - | Plugin que provee modelos de IA (ej: openai_api_compatible) | Dify plugin system |
| RAG | - | Retrieval Augmented Generation — búsqueda semántica en documentos | Documentación, Dify |
| Scoring | - | Puntuación 0-100 de un lead basada en su engagement | Campañas, leads |
| SPA | Single Page Application | Aplicación web que carga una sola página y actualiza contenido dinámicamente | Hub, Dashboard |
| Twenty CRM | - | CRM open-source para gestión de contactos y leads | CRM, leads, empresas |
| Weaviate | - | Vector database open-source | RAG en Dify |
| Workflow | - | Flujo automatizado en n8n o Dify | Automatización |
| xAI Grok | - | Modelo de lenguaje de xAI (alternativa a GPT, deprecado — sin créditos) | LLM para clasificación |
